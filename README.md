# Sales Performance Dashboard using Power BI

## Project Overview
This project analyzes retail sales data and presents business insights using an interactive Power BI dashboard. The dataset was cleaned and prepared before visualization.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- Data Cleaning
- Dashboard Visualization

## Dashboard Features
- Total Sales overview
- Total Profit overview
- Order Count
- Quantity Sold
- Monthly Sales Trend
- Region-wise Sales Analysis
- Category Distribution
- Profit by Sub-Category
- Interactive Filters

## Dataset
Sales dataset containing:
- Order details
- Product category
- Region
- Profit
- Sales
- Quantity

## Key Insights
- West region generated the highest sales.
- Technology category contributed maximum revenue.
- Some sub-categories showed negative profit.
- Sales performance changed across months.
- Profitability varied across product categories.
